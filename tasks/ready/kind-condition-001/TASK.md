# Implement a condition for two exact kinds

## Context

Complete the specified operations.

## API

```go
func RequiresPermit(kind string) bool
```

## Requirements

- Return true for the exact kind car.
- Return true for the exact kind truck.
- Return false for every other string, including empty input.
- Matching is case-sensitive and does not trim whitespace.

## Constraints

- Use only the Go standard library.
